# Northwind Data Analysis Portfolio Project

A comprehensive data analysis and visualization project using the classic Northwind database, SQL Server, and Power BI. This project demonstrates end-to-end data engineering and business intelligence skills through exploratory data analysis, KPI calculations, and interactive dashboards.

## 📊 Project Overview

This portfolio project showcases:
- **Database Design**: Northwind sample database with normalized schema
- **SQL Analysis**: Complex queries for business insights and KPI calculations
- **Data Exploration**: Ad-hoc queries for discovering patterns and trends
- **Power BI Dashboards**: Interactive visualizations and business intelligence dashboards
- **Data Insights**: Interesting findings from exploratory analysis

## 🚀 Getting Started

### Prerequisites
- SQL Server (2016 or later) or SQL Server Express
- Power BI Desktop
- Basic understanding of SQL and data analysis

### Quick Start

1. **Setup Database**: Follow the [SETUP.md](setup/SETUP.md) guide to restore the Northwind database
2. **Run SQL Scripts**: Execute the database schema and view creation scripts
3. **Open Dashboard**: Load the Power BI file and connect to your SQL Server instance
4. **Explore**: Interact with visualizations and run ad-hoc queries

For detailed setup instructions, see [SETUP.md](setup/SETUP.md)
