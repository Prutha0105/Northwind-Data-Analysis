# Northwind Data Analysis Project - Requirements

## Software Requirements

### Database
- SQL Server 2016 or later
  - SQL Server Express (Free): https://www.microsoft.com/en-us/sql-server/sql-server-downloads
  - SQL Server Developer Edition (Free): https://www.microsoft.com/en-us/sql-server/sql-server-downloads
  - SQL Server Standard/Enterprise (Commercial)

- SQL Server Management Studio (SSMS) - Latest version
  - Download: https://docs.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms
  - Free

### Business Intelligence & Visualization
- Power BI Desktop (Latest version)
  - Download: https://www.microsoft.com/en-us/power-bi/desktop
  - Free

### Operating System
- Windows 10 (Version 1909 or later) or Windows 11
- Or Windows Server 2016/2019/2022

## System Requirements

### Minimum Specifications
- Processor: 1.4 GHz 64-bit processor compatible with x64 instruction set
- Memory (RAM): 4 GB minimum, 8 GB recommended
- Storage: 5-10 GB free disk space
- Display: 1024 x 768 resolution minimum

### Network
- Internet connection for initial downloads
- Local network access (if on different machines)

## Development & Optional Tools

### Recommended Tools
- Visual Studio Code: https://code.visualstudio.com/

- Git for version control

### Optional Tools
- Azure Data Studio (Alternative to SSMS)
  - Download: https://docs.microsoft.com/en-us/sql/azure-data-studio/download-azure-data-studio
  - Free, cross-platform

- Tableau (if exploring alternative BI tools)
- Other SQL editors for personal development

## Version Information

### Verified Versions
- SQL Server 2016 SP2 or later
- SQL Server 2017 RTM or later
- SQL Server 2019 RTM or later
- SQL Server 2022 RTM or later
- SSMS 18.0 or later
- Power BI Desktop (2021.12 or later recommended)

### compatibility Notes
- SQL Server Express limitations: 10 GB database size limit
- Power BI free trial: 60-day trial, then requires subscription
- Views may require SQL Server 2016 SP1 or later for optimal performance

## Database Size & Performance

### Expected Database Size
- Northwind database: ~3-5 MB uncompressed
- With indices and views: ~5-10 MB
- Power BI file: ~5-20 MB depending on data size

### Expected Performance
- Database creation: < 1 minute
- Dashboard initial load: ~5-10 seconds (LAN connection)
- Query execution time: < 5 seconds for most queries
- Data refresh: ~10-30 seconds depending on connection
